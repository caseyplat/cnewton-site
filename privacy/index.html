PRIVACY POLICY

Source Code collector

A personal, read-only tool that Casey Newton uses with his own Google account. Effective September 6, 2026.

// WHAT IT IS

Source Code collector is a small program that runs on Casey Newton’s own computer. It looks at his own Gmail and Google Calendar to note when he last corresponded or met with people he already keeps notes on, so that his private contact records stay current. It is not offered to the public, has no other users, and has no website beyond this page.

// WHAT IT ACCESSES

  • Gmail, read-only: message headers (sender, recipients, date, subject) for messages exchanged with addresses already in his contact records. It does not read message bodies or attachments.

  • Google Calendar, read-only: event titles, dates and attendee addresses for events on his own calendar.

  • It never sends email, creates or changes events, or modifies anything in the Google account.

// HOW THE DATA IS USED AND STORED

  • The only thing recorded is a dated note that a conversation or meeting took place, together with the subject or event title and a link back to the original item in Gmail or Google Calendar.

  • Those notes are stored in files on the owner’s computer alongside his private contact records. They are not uploaded to any server, shared with any third party, sold, or used for advertising.

  • No data obtained from Google APIs is used to train or improve any artificial-intelligence or machine-learning model.

  • Access tokens are stored only on the owner’s computer, in a location readable only by his user account.

// GOOGLE API SERVICES USER DATA POLICY

Source Code collector’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

// RETENTION AND REVOCATION

  • Recorded notes are kept until the owner deletes them; because they live in local files, deleting them removes them completely.

  • Access can be revoked at any time from the third-party access page of the Google account, after which the program can no longer read anything.
